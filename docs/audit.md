# Audit record

This package went through two independent audits before publication. The v2 audit (6x + DM542T in one steel box, 28 findings) shaped the mechanics and safety design. The v3 audit below (24 findings) covers the 4x build. All findings were applied. The current v4 layout (steel power box + printed 24 V controller box, two controller variants) was audited again before publication; that record is at the end of this file.

**ID mapping:** the v3 findings below use the old part IDs. E1 → VA1, E2/E3 → PW1/PW2, E4/E5 → PW3/PW4, E6 → PW5, E7–E9 → PW6–PW8, E10 → PW9, E11 → PW10, E12 → PW11, E13 → PW12 (now the steel power box only), E15 → PW14, E16 → PW15/VA3, E17/E18 → CC2/CC3, E20 → PW16, E21 → CC4/CC5, E22 → CC6, FX10 → PW17.

**Correction:** finding #2 below estimated the board at ≈170 × 115 mm from a wiki image. Both FluidNC 4x and 6x boards are **125 × 85 mm**, verified from Bart Dring's EasyEDA layout ([enclosure/README](../enclosure/README.md)).

## v3 audit (01, 02, YAML, wingcut TOML, bom.csv)

*2026-11-05. I did not edit 01, 02, the YAML, the TOML or bom.csv. Anything that checked out is not listed.*

**Checked and fine:**
- **4x v1.1 board.** Terminal names (TB1/TB3/TB4/TB5 motors, TB7 power, TB10 = gpio.12 / VMot / gpio.4 / VMot), the i2so pins, UART gpio.26/2, the input pins and their Gnd terminals, and the StallGuard pad order (A/Z/Y/X) all match the wiki pinout image. Inputs have external pull-ups, so NC-to-Gnd needs no attribute. The MOSFETs are low-side with flyback diodes.
- **DC60.** Terminals 1(+)/2(−) load and 3(+)/4(−) control; control range 3.5–32 V (1500 Ω, so ≈16 mA at 24 V); load 3–60 V, 0.02–7 A; t_on 0.1 / t_off 0.3 ms; the datasheet does require a fast diode on inductive loads; input/output/base isolation is 4 kV. The freewheel diode orientation is correct.
- **Mean Well.** LRS-100/150F input 85–264 VAC with no selector; adjust ranges 21.6–28.8 V and 32.4–39.6 V; output isolated from FG.
- **Arithmetic.** The wire numbers (8.7 Ω/m, 12.6 Ω, I_full ≈ 2.70 A, S table, dummy-load currents, the tension/deflection check) are correct. The BOM sections sum to $896.
- **Config files.** Every wingcut TOML key exists in `config.rs` (deny_unknown_fields). The `limits` match FluidNC's soft ranges [0, 1000] and [mpos − max_travel, mpos], and the tram sign (`z mpos_mm = +d`) is right. The YAML keys exist in FluidNC v4.1.1 (`Axes.cpp`, `Homing.h`, `Motor.cpp`, `Spindle.cpp`). wingcut's Pause really does send `!` and then `0x9E` at `Hold:0` (`machine/src/controller.rs`).
- **v2 fixes that did not regress:** #1, #5–#9 (moot without K1), #11–#13, #15–#28. The ones that did regress are #2, #10 and the v2 antenna and lid-strap rows; see findings 3, 4 and 5.
